DREAM Detector Diagnostics#

This page is primarily intended for instrument scientists and other experts.

ESSdiffraction has some tools for inspecting the DREAM detector based on recorded event data. This notebook gives an overview of the available tools.

Voxel Viewer#

The FlatVoxelViewer is a visualization for inspecting individual voxels. It shows a 2D histogram of recorded counts. The image axes correspond to multiple logical dimensions of the detector banks each. The dims are flattened in the order shown as the axis labels Each bin in the image corresponds to exactly one detector voxel.

Hover over the image to see the precise index and value of each bin.

[1]:

import scipp as sc

from ess import dream
from ess.dream.data import simulated_diamond_sample
from ess.dream.diagnostics import FlatVoxelViewer

[2]:

%matplotlib widget

Load simulated test data and compute histograms:

[3]:

raw = dream.io.load_geant4_csv(simulated_diamond_sample())
dg = sc.DataGroup({
    k: v['events'].hist()
    for k, v in raw['instrument'].items()
})

Display 2D view:

[4]:

FlatVoxelViewer(dg)
